# 전역이 아닌 포커스별 컴파트먼트 추적

`GUID_COMPARTMENT_KEYBOARD_OPENCLOSE`는 스레드 매니저의 전역 컴파트먼트에서도, 포커스된
문서/컨텍스트의 컴파트먼트에서도 조회할 수 있다. 전역 컴파트먼트 구독은 구현이 단순하지만,
실제 테스트 결과 이 PC에서는 앱(창)마다 한/영 입력 상태가 독립적으로 유지되는 것으로
확인되었다 — 즉 전역 값만으로는 실제로 포커스된 창의 상태를 정확히 반영하지 못한다.
이는 CLAUDE.md가 요구하는 "오차 없이, 실시간으로" 표시한다는 목표와 정면으로 충돌하며,
배경 섹션에서 이미 지적된 "표시와 실제 상태가 어긋나는" 문제를 다른 형태로 재발시킨다.

이에 `ITfThreadMgrEventSink::OnSetFocus`로 포커스 전환을 감지하고, 전환될 때마다 이전
컨텍스트의 컴파트먼트를 `UnadviseSink`, 새 컨텍스트의 컴파트먼트를 `AdviseSink`로 교체하는
방식을 택한다. 구현 복잡도는 늘지만, 폴링 없이도 포커스별 정확한 상태를 유지할 수 있는
유일한 방법이다.
